# 📝 Text Analyzer

A simple interactive text analysis web application built using Python and Streamlit.

## 🚀 Live Demo

[Try the Text Analyzer](https://app-text-analyzer.streamlit.app/)

## ✨ Features

- Count words
- Count characters
- Count sentences
- Find the 5 most common words
- Interactive web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Regular Expressions
- Collections Counter
